Приложение робота работает на телефоне или компьютере, который установлен на роботе. Оно взаимодействует с корпусом робота, транслирует видео контроллеру и выполняет политики вождения.

- [Android](android/README.ru_RU.md): установите APK из последнего релиза или соберите его в Android Studio (откройте `robot/android`).
- [iOS](ios/README.ru_RU.md) (бета): соберите его с помощью Xcode; в App Store его пока нет.
- [Linux](linux/README.ru_RU.md): версия на Python для компьютера с Linux и камерой.
