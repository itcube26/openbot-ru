Существует несколько способов управления роботом OpenBot.

## Bluetooth-контроллер

Самый простой способ управлять роботом — подключить игровой контроллер по Bluetooth. Большинство BT-игровых контроллеров должны работать. Мы протестировали [контроллер PS4](https://www.amazon.de/-/en/Sony-Dualshock-Gamepad-Playstation-Black/dp/B01LYWPQUN), [контроллер XBox](https://www.amazon.de/-/en/QAT-00002/dp/B07SDFLVKD) и несколько сторонних контроллеров, таких как [X3](https://www.amazon.com/Controller-Wireless-Joystick-Bluetooth-Android/dp/B08H5MM64P).

## [Node.js-контроллер](node-js)

Этот контроллер требует, чтобы ваш телефон и компьютер (например, ноутбук, Raspberry PI) были подключены к одной WiFi-сети. После успешного подключения вы получаете живое видеопередачу с низкой задержкой и можете использовать клавиатуру для управления роботом из браузера.

Отдельная благодарность Ivo Zivkov [izivkov@gmail.com](mailto:izivkov@gmail.com) за разработку.

## [Python-контроллер](python)

Этот контроллер требует, чтобы ваш телефон и компьютер (например, ноутбук, Raspberry PI) были подключены к одной WiFi-сети. После успешного подключения вы получаете живой RTSP-видеопоток и можете использовать клавиатуру для управления роботом из терминала. Вы можете использовать скрипт на Python как шаблон для разработки собственного контроллера.

Отдельная благодарность Ivo Zivkov [izivkov@gmail.com](mailto:izivkov@gmail.com) за разработку.

## [Flutter-приложение контроллера](flutter)

Это приложение-контроллер служит пультом дистанционного управления для машины OpenBot аналогично BT-контроллеру (например, PS3/4 или Xbox). Оно работает на другом устройстве Android/iOS и, помимо управления, поддерживает живую трансляцию видео/аудио. Оба телефона должны находиться в одной Wi-Fi сети, либо один телефон должен быть подключён к точке доступа другого.

## [Веб-серверный контроллер](web-server)

Это облачная версия локального Node.js-контроллера. Он позволяет дистанционно телеуправлять роботом OpenBot через интернет.
